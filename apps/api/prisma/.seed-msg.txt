feat(api): seed the reference currencies, and run the seed from Prisma's hook (ADR-0003, ADR-0013)

The admin names a primary currency through a foreign key, and nothing ever put a row in that
table, so the documented IDR default could not succeed on a fresh database.
seedReferenceCurrencies upserts IDR (Rp, 0 decimals), VND (dong, 0) and USD ($, 2) per ADR-0003.
It upserts with an empty update, so re-running leaves an operator's edit alone - and the spec
proves that rather than assuming it.

Verified against the dev database: three currency rows and one admin row, the admin's primary
currency resolving, and a second run changing neither.

seed.cli.ts is the entry point Prisma's hook and a manual first boot both call; the order is
currencies before the admin, because the account cannot exist before the currency it points at.
